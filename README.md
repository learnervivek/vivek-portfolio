# Vivek Kumar Gupta - Portfolio Website

A modern, responsive portfolio website showcasing my work as a passionate web developer specializing in the MERN stack. This project is built with Next.js 14, React 18, TypeScript, and Tailwind CSS for a seamless, high-performance user experience.

## 🌟 Features

- **Modern Design**: Beautiful, responsive UI with dark/light theme support
- **Smooth Animations**: Blur fade effects and smooth transitions for engaging interactions
- **SEO Optimized**: Built with Next.js for server-side rendering and optimal SEO
- **Dark Mode Support**: Toggle between light and dark themes using next-themes
- **Component Library**: Custom UI components powered by Shadcn UI and Radix UI
- **Markdown Support**: Dynamic content rendering with React Markdown
- **Code Highlighting**: Syntax-highlighted code blocks using Shiki
- **Responsive Design**: Mobile-first approach ensuring compatibility across all devices

## 🛠️ Tech Stack

### Frontend Framework & Language

- **Next.js** 14.2.4 - React framework for production
- **React** 18.3.1 - UI library
- **TypeScript** 5.8.3 - Type-safe JavaScript
- **Tailwind CSS** 3.4.17 - Utility-first CSS framework

### UI Components & Styling

- **Shadcn UI** - High-quality React components
- **Radix UI** - Primitive components for building UIs
  - React Avatar
  - React Icons
  - React Separator
  - React Slot
  - React Tooltip
- **Lucide React** 0.395.0 - Beautiful icon library
- **Tailwind CSS Animate** - Animation utilities
- **Tailwind CSS Typography** - Typography plugin for styled content

### Animation & Motion

- **Framer Motion** 11.18.2 - Production animation library
- **Motion** 12.7.4 - Motion library for React

### Content & Markdown

- **React Markdown** 9.1.0 - Markdown to JSX renderer
- **Remark** - Markdown processor ecosystem
  - remark-parse - Markdown parser
  - remark-gfm - GitHub Flavored Markdown support
  - remark-rehype - Remark to rehype bridge
- **Rehype** - HTML processor
  - rehype-stringify - HTML serializer
  - rehype-pretty-code - Syntax highlighting
- **Gray Matter** 4.0.3 - YAML front matter parser
- **Shiki** 1.29.2 - Syntax highlighter
- **Unified** 11.0.5 - Text processing ecosystem

### Utilities

- **Next Themes** 0.3.0 - Next.js theme management
- **Class Variance Authority** 0.7.1 - CSS class composition
- **CLSX** 2.1.1 - Conditional CSS classes
- **Tailwind Merge** 2.6.0 - Merge Tailwind CSS classes

### Development Tools

- **ESLint** 8.57.1 - Code linting
- **PostCSS** 8.5.3 - CSS transformations
